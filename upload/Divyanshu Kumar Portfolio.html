      Case study · in development

      AttendanceMaster

      After an exam, every centre sends back scanned attendance sheets. Each row carries a Copy No, written by hand, that ties a student to an answer script. AttendanceMaster reads those numbers so people only have to check them.

      Status. The handwriting model is still being trained. An accuracy of about 20–40% is reported for the handwriting recogniser, but no held-out test set or metric has been defined yet, so I do not present it as a benchmark. Real sheets and student data are confidential. The sheet below is a made-up specimen.

        Inside the reader

        The recogniser is a CRNN: a convolutional stack that turns the strip into a sequence of columns, a two-layer bidirectional LSTM that reads that sequence, and CTC decoding that outputs a digit string without anyone labelling where each digit sits.

        Why one wrong digit matters

        A copy number is only useful if every digit is right. That makes exact-match accuracy much harsher than per-digit accuracy. This is plain arithmetic with sliders, not a measurement of AttendanceMaster.

        What is measured, and what is not

        Defined
        The reader, the preprocessing, the training loop, the review workflow, and how verified rows feed the next training run.
        Reported
        About 20–40% accuracy for handwritten Copy No recognition. The metric and test set behind it are not established.
        Not yet
        A held-out test set, a log of model runs with measured results, and sanitised error examples.
        Next
        Define the metric and test set, log every model version with its results, and keep studying failures to pick the next experiment.
